────────────────────────────────────────────────────────────────
一、这是什么问题
────────────────────────────────────────────────────────────────
Windows 26H2（build 26300.10075，累积更新 KB5132057）更新后，
任务栏透明软件 TranslucentTB 会完全失效：

  · 任务栏变回系统默认的不透明深色
  · 软件进程还在、托盘图标也在、配置里写的还是"透明"
  · 重启软件 / 重启资源管理器 / 重置安装包，全都没用

根本原因：这一版系统的 shell 不再和 TranslucentTB 的接管层对话，
         用户态怎么设置都无效，只能回滚这一版更新。

────────────────────────────────────────────────────────────────
二、怎么修（三步，约 2 分钟操作 + 10~30 分钟等待）
────────────────────────────────────────────────────────────────
 1) 把本文件夹里的 scripts 整个解压出来（不要只拖单个脚本）
 2) 右键 Fix-RollbackUpdate.ps1 → "使用 PowerShell 运行"
    （脚本会自己申请管理员权限；窗口别关，卸载过程 10~30 分钟）
 3) 完成后重启电脑
    桌面会生成 TBTB-verification.txt，看到 VERDICT: FIXED 就是修好了

 不想用脚本，也可以手动执行（管理员 PowerShell）：
     dism /online /remove-package /packagename:"Package_for_RollupFix~31bf3856ad364e35~amd64~~26100.10075.1.25" /norestart
     退出码 3010 = 成功，需要重启
